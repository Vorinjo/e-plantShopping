# Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux shopping cart application for an online
houseplant store. Customers can browse 18 unique plants grouped into three
categories, add plants to their cart, change quantities, remove items, and view
the dynamically calculated total cost.

## Features

- Responsive landing page with a background image and **Get Started** button
- Three plant categories with six unique plants in each category
- Product thumbnails, names, descriptions, prices, and Add to Cart buttons
- Dynamic cart badge showing the total number of items
- Redux Toolkit cart state management
- Increase, decrease, delete, continue-shopping, and checkout controls
- Navigation links for Home, Plants, and Cart

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
